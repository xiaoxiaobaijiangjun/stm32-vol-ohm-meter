# stm32-vol-ohm-meter

基于 STM32F103C8T6 的便携式电压 / 电阻检测仪。1.8 寸 TFT 实时显示，
单按键切换三种工作模式，蜂鸣器提供量程与通断提示。

## 功能特性

- 电压测量：0–5V / 5–15V 双量程，基于 1.65V 精密基准的差分测量，软件自动识别量程并显示正负号
- 电阻测量：0R–1K / 1K–100K 双量程，约 1.2mA 恒流法 + 10k 分压法，量程自动切换
- 通断检测：电阻 ≤ 15Ω 连续蜂鸣，超量程显示 `OL.`
- 红黑表笔反接保护（P-MOS），支持反接测量
- 12 位 ADC + DMA 连续采样，64 轮累加平均 + 16 点滑动平均两级滤波
- 使用 STM32 内部 VREFINT（1.21V）对 ADC 结果实时校准，消除供电波动影响
- 量程越界 / 接近上限时蜂鸣器提示（可作粗略"在线查阻值"提示）
- 板载 12 颗红色 LED 电平指示；Type-C 供电，全插件器件，手工焊接友好

## 硬件架构

### 信号链

```mermaid
flowchart LR
    A[红黑表笔输入] --> B[分压网络 / 恒流源]
    B --> C[LM358 运放调理<br/>1.65V 电平移位]
    C --> D[ADC1 7通道扫描]
```

### 引脚分配

| 外设 | 引脚 | 说明 |
|---|---|---|
| ADC1_IN1 | PA1 | 1.65V 基准采样（ref165） |
| ADC1_IN2 | PA2 | 电压 0–5V 通道（vol1） |
| ADC1_IN3 | PA3 | 电压 5–15V 通道（vol2） |
| ADC1_IN4 | PA4 | 电阻 0–1K 通道（res_in1） |
| ADC1_IN5 | PA5 | 电阻 1K–100K 通道（res_in2） |
| ADC1_IN6 | PA6 | 恒流源参考节点（ref230） |
| ADC1 VREFINT | 内部 | 1.21V 内部基准，用于 ADC 校准 |
| SPI1（重映射） | PB3=SCK, PB5=MOSI | ST7735 TFT（128×160，软件驱动） |
| LCD 控制 | PB0=BL, PB1=CS, PB10=DC, PB11=RES | 背光 / 片选 / 数据命令 / 复位 |
| MODE 按键 | PB9（EXTI 下降沿） | 模式切换：电压 → 电阻 → 通断 |
| BEEP 蜂鸣器 | PA7 | 量程 / 通断提示 |
| SWD 调试 | PA13/PA14 | ST-Link |

> 注：SPI1 重映射到 PB3/PB5，是因为默认的 PA5/PA6/PA7 已被 ADC 占用。

### 关键电路（对应原理图，见 `docs/hardware/`）

- 电源：Type-C 5V 输入 → 滑动开关 → 3.3V LDO；XD7660 电荷泵产生 -5V 供运放
- 基准：TL431（0.5%）精密基准 + 分压得到 1.65V 参考电平
- 电压前端：分压网络（10k+3.3k 与 100k+10k）经 LM358 电平移位，使 ADC 输入落在 1.65V 附近
- 电阻前端：由基准网络产生约 1.2mA 恒流；1K–100K 档使用 10k 已知电阻分压
- 保护：P-MOS 反接保护，支持表笔反接测量

## 测量原理

所有 ADC 读数都先经 VREFINT 校准：

```
V_channel = ADC_raw / VREFINT_raw × 1.21  [V]
```

### 电压模式

前端把输入分压并抬升到 1.65V 参考附近，软件减去实测基准值再按分压比还原：

```
0–5V 档： V_in = (vol1 − ref165) × 13.3 / 3.3
5–15V 档：V_in = (vol2 − ref165) × 11
```

量程识别：比较两路通道的变化量，哪一路在动就显示哪一路（启发式，见"已知问题"）。

### 电阻模式

恒流源电流由两个基准节点计算得出（自校准，不依赖电阻精度）：

```
I = (2 × ref165 − ref230) / 1000  [A]，约 1.2mA

0–1K 档：   R = res_in1 / I
1K–100K 档：R = 10k × res_in2 / (2 × ref165 − res_in2)
```

### 通断模式

复用电阻前端，R ≤ 15Ω 时蜂鸣器持续鸣响。

## 软件架构

```
Core/        CubeMX 生成的 HAL 层（时钟、ADC、DMA、SPI、GPIO）
hardware/    ST7735 LCD 驱动（函数指针注册式）、按键消抖驱动
middle/      滑动平均滤波（电压浮点 / 电阻整型）
app/         应用层：三种模式页面、测量算法、非阻塞按键状态机
```

主循环为裸机前后台结构：`main()` 初始化后循环调用 `cycle_task()`；
ADC 转换在 DMA 中断中累加，凑满 64 轮后置标志，主循环取数并刷新显示。

## 构建与烧录

1. 使用 STM32CubeIDE（≥ 1.13，HAL F1 1.8.6）以 *Existing Projects* 方式导入本目录
2. 工程名：`stm32-vol-ohm-meter`，芯片 STM32F103C8T6，HSE 8MHz ×9 = 72MHz
3. 用 ST-Link（SWD）连接 PA13/PA14，选择 `stm32-vol-ohm-meter Debug` 运行配置烧录
4. 板上硬件：ST 最小系统板插到载板排针，Type-C 供电

## 校准说明

当前版本电压通道的零点偏移（offset）硬编码为 5mV（见 `app/app_task.c` 中
`offset_val`），这是原作者在输入端短接 GND 时实测的跟随器输出偏移。
焊接完成后的首轮调试建议：

1. 输入端接 GND，记录显示偏移；
2. 用精度较好的万用表对照 3–4 个电压点（如 1V / 3.3V / 5V / 12V）；
3. 如偏差稳定，修改 `offset_val` 即可。

迭代计划中已包含"长按进入校准模式 + 参数存 Flash"功能（见下）。

## 已知问题与迭代计划

- **LCD 填屏参数看似颠倒**：`lcd_fill` 调用传的是 `(height, width)` 而非
  `(width, height)`。在竖屏（MADCTL 含 MV 行列交换）下这个转置窗口恰好
  覆盖全屏，**不要"修复"它**，否则底部会留黑边
- 电压量程自动切换是启发式（哪路通道变化大就显示哪路），量程判断不够严谨，
  计划改为基于分压网络数学关系的判据
- 零点偏移硬编码，计划加入按键校准流程并存入 Flash（使用片上 Flash 最后一页）
- 当前无串口输出，调试不便，计划增加 UART 日志（可选 115200 调试口）
- F103 无硬件浮点单元，浮点运算占 CPU 较多，计划评估定点化或降低刷新频率
